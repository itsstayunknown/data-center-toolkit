# Changelog

## 0.1.0

Initial evidence-first Linux terminal toolkit release candidate.

- Keyboard-driven TUI with breadcrumbs, search, contextual help and responsive collection.
- Host identity and capability-aware Linux evidence.
- Resources, process details, systemd services and bounded selected journals.
- Networking, explicit connectivity checks, storage inventory and disk health.
- Confirmed and revalidated local mount/unmount workflow.
- NVIDIA telemetry and compute-process evidence.
- Quick Triage with evidence, confidence and UNKNOWN-aware diagnostics.
- Sanitized incident reports and integrity manifests.
- Target and inventory abstractions with local, OpenSSH-config and static YAML providers.
- Shared local, fixture and read-only OpenSSH executors; one remote target at a time.
- Synthetic fixtures, deterministic execution tests and release scenario matrix.

Fleet execution and NetBox/Nautobot integrations remain future design only.
No repository publication, PyPI upload or GitHub release is part of this candidate.
